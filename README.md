# NovelAI PostProcessor

This repository for the post processing of the images generated by NovelAI.

---

## upscale

Upscaling image by scaler factor 4. 

```
\parent_folder # you should specify the full path of "parent_folder" in command line arguments.
    |
    `--- _01_base # fixed name
            |
            `--- image01.png # the original files to be upscaled. ".png" is only allowed.
            |
            `--- image02.png
```

---

## jpeg_converter

Converting `.png` image to `.jpeg`.

```
\parent_folder
    |
    `--- image01.png # the files to be converted to .jpeg
    |
    `--- image02.png

```
